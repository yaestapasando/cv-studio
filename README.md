# Proyecto Base: CV Studio

Este es un proyecto base que sirve como punto de partida para el desarrollo de una aplicación web destinada a la creación y gestión de CVs (Currículum Vitae).

## Estructura del Proyecto

- `init-request.md`: Archivo Markdown que contiene la demanda inicial para la creación de la aplicación web de gestión de CVs.

## Proceso de Desarrollo

1. **Revisión de la Demanda**: El archivo `init-request.md` describe los requisitos iniciales para la aplicación.

2. **Ramas de Desarrollo**: Se crearán ramas nuevas a partir de la rama `main` para cada agente de IA y modelo utilizado. Por ejemplo:
   - `claude/sonet-4.6`
   - `codex/chatgpt-5.4`

   Cada rama representará el trabajo realizado por un agente específico, permitiendo comparar y fusionar implementaciones de diferentes modelos de IA.

3. **Generación del PRD**: Una vez creada la rama específica, se solicita al agente de IA correspondiente que genere un archivo `PRD.md` (Product Requirements Document) en esa rama, el cual incluirá un listado detallado de tareas que el agente debe completar para implementar la aplicación.

## Próximos Pasos

- Leer y analizar `init-request.md`.
- Crear ramas específicas para cada agente de IA y modelo.
- En cada rama, generar `PRD.md` utilizando el agente correspondiente y comenzar el desarrollo basado en las tareas definidas en el PRD.

## Contribuciones

Este proyecto está diseñado para ser utilizado con agentes de IA para automatizar el proceso de desarrollo. Las contribuciones manuales pueden incluir mejoras al proceso o documentación adicional.
